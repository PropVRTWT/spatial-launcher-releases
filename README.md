# Spatial Launcher releases

Installers for **Spatial Launcher** by [PropVR](https://propvr.ai). The source code is not here.

**Install:** open the [latest release](https://github.com/PropVRTWT/spatial-launcher-releases/releases/latest) and run `Spatial-Launcher-Setup-<version>.exe`.

**Updates:** Spatial Launcher 1.2.0 and later update themselves from this page. Each release's `latest.json` is signed with PropVR's release key, and the launcher installs only releases with a valid signature.
